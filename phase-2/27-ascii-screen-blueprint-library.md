# 27 — ASCII Screen Blueprint Library

**Version:** 1.0  
**Status:** Accepted normative hierarchy  
**Gate:** 2.5 — High-Fidelity System

## Legend

```text
[ACTION]          interactive control
<STATE>           selected state
{DATA}            real content or structured fixture
······            optional or conditional region
! LABEL           explicit limitation, error, or unavailable state
→                 navigation or evidence relationship
```

ASCII defines hierarchy and relationship. Document 26 and the token file define
visual treatment. Exact rendering is validated in the browser.

## 10. System states

```text
EMPTY          No published artifact matches this section. [VIEW JOURNAL]
COMING SOON    Work is registered but not published. [DISCUSS THIS TOPIC]
UNAVAILABLE    Source unavailable. Read the limitation. [OPEN LIMITATION]
CLOSED         Artifact exists but is not public. [READ PUBLIC METHOD]
ERROR          The request could not be completed. [TRY AGAIN] [USE STATIC VIEW]
```

## 11. Blueprint acceptance

- Every global action appears visibly at least once.
- Both gateways have equal hierarchy.
- Every unsupported result is labeled honestly.
- Mobile remains complete without desktop spectacle.
- Evidence Depth is visibly one canonical document.
- No blueprint requires invented findings, figures, client names, or estimates.
